Predicción de demanda e inventario

El microservicio lee productos, lotes y movimientos del inventario relacional, guarda una copia flexible en MongoDB, limpia los registros y calcula una demanda estimada para los próximos 7 días.

Como el backend actual no tiene una tabla formal de ventas, el modelo usa los movimientos tipo Exit como aproximación de demanda.
